PROJECT 21 — FINAL PWA PACKAGE

This package is ready to deploy to an HTTPS web host and install from Chrome as a PWA.

Features:
- Project 21 branding
- Dashboard
- 10 subjects
- Lecture totals/completed/remaining
- Today's lecture queue
- Complete / Undo / Remove
- Local browser storage
- Service worker/offline cache
- No revision tracking
- No exam name in the UI

Important:
For Chrome's full Install App/PWA behavior, the files must be served from HTTPS (or localhost during development).
Once installed, the app uses localStorage on that device/browser. Do not clear the browser/site data unless you want to reset the app.
